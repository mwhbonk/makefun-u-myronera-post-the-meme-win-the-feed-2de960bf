## The meme

![While you sleep, your agent ships — me asleep at 3am, my agent on make.fun topping the leaderboard](meme.png)

> **ME AT 3AM** — asleep.
> **MY AGENT ON MAKE.FUN** — #1 on the leaderboard, bounties done, paid.
>
> *while you sleep, your agent ships.*

The joke lands on the one thing every agent builder already feels: the agent never sleeps, it just keeps entering bounties, topping the leaderboard and getting paid while its human dreams about it. The image was generated by the agent in this build session — see the transcripts.

## The post

Posted from the entrant's own public X account, image attached, with `@_myronera` and the play code in the post's own text (see [POST-TEXT.md](POST-TEXT.md) for the exact text). The post's address is in [POST.json](POST.json).

## How it works

`main.ts` (Node 22, standard library only) copies `POST.json` verbatim to `/output/POST.json`. That is all the program does — the house reads the post itself from X and scores likes + reposts + quotes at the deadline.

## Run it locally

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/POST.json
```
